# Acervo dos Nove

Site tributo ao Slipknot, feito por fã.

## Como colocar fotos

1. Abra a pasta [`fotos`](fotos) e clique em **Add file → Upload files**.
2. Arraste as fotos com os nomes exatos da lista em `fotos/LEIA-ME.txt` (minúsculas, sem acento, `.jpg`).
3. Clique no botão verde **Commit changes**.
4. Em um ou dois minutos as fotos aparecem no site.

Para ver onde fica cada espaço, abra o site com `#espacos` no fim do endereço.

Os créditos de cada foto ficam no `index.html`, no bloco `const FOTOS`.
